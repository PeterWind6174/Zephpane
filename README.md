# Zephpane

Zephpane 是一个开发初期的跨平台远程桌面项目，目标是在 Windows、macOS 和 Linux 之间切换整屏控制与窗口融合。融合模式让远端已打开的应用以本地窗口呈现，应用进程和未保存的内容继续留在原来的机器上。

## 当前进度

当前仓库提供架构参考、协作规范和目录骨架。首个原型面向 Windows 11 x64 被控端与 Apple Silicon macOS 控制端，目标是把 Windows 上已打开的记事本和浏览器分别显示在 Finder 旁边，并将键盘输入送到选中的窗口。可运行客户端、构建命令和双机验收结果将在实现后补充。
